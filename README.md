# إقفال صناديق الكاشير — الإصدار 4.8

تطبيق جوال لإقفال صناديق الكاشير اليومية وتقاريرها.

## محتوى المستودع
| الملف | الاستخدام |
|---|---|
| `index.html` و `manifest.webmanifest` و `sw.js` والأيقونات | واجهة التطبيق التي تُثبّت على الجوال من GitHub Pages |
| `link.txt` | رابط النظام في Google Apps Script (ينتهي بـ `/exec`) |
| `gas/` | ملفات النظام الخمسة: `Code.gs` و `Index.html` و `Js1.gs` و `Js2.gs` و `Js3.gs` |

## التشغيل
1. الصق ملفات مجلد `gas/` في مشروع Apps Script، وانشره كتطبيق ويب (Execute as: Me — Who has access: Anyone).
   - إذا كان جدول البيانات في حساب العميل: من **Project Settings ← Script Properties** أضف `SHEET_ID` وقيمته رقم جدول العميل أو رابطه (بعد ما يشاركه العميل معك بصلاحية «محرّر»).
   - اختياري: أضف `SETUP_CODE` برمز تختاره، ولا يقدر أحد ينشئ حساب مدير النظام إلا به.
   - أول دخول للنظام ينشئ حساب **مدير النظام** وله كل الصلاحيات.
2. انسخ رابط النشر وضعه في `link.txt` بدل السطر الموجود.
3. من **Settings ← Pages** اختر الفرع `main` والمجلد `/ (root)` ثم **Save**.
4. افتح `https://alhakemi209-max.github.io/cashier-closing-system/` من الجوال، ثم «إضافة إلى الشاشة الرئيسية».

## التحديث لإصدار جديد
- استبدل ملفات مجلد `gas/` بالجديدة، والصقها في Apps Script، ثم **Deploy ← Manage deployments ← New version** حتى يبقى نفس الرابط.
- واجهة GitHub لا تحتاج تعديل عند تحديث النظام.
